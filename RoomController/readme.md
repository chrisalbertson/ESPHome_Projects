# Room Controllers

A Room Controller is a small graphic screen used to the smart devices in one room or area. It is not a large general purpose dashboard or status dislay.   It is better to think of a Room Controller as smart light switch.

Naming.

Room controllers have a multi-part name that describs ther funtionand hardware as follows

**rmctl**-<**area name**>-<**hardware**>

- [ ] **area name** is the same as the area used in Home Assistent.  The ESPHon=me device will be asigned to this location in Home Assistant
- [ ] **hardware** is the name of the board we are using
